# Reusable Observation Sheet

Copy this template into an approved, access-controlled study note. Do not commit completed participant notes to this repository.

## Session Header

```text
Session code: S-____
Date/time: [study record, not repository]
Facilitator: [study record, not repository]
Game / issue: ____________________
Outcome mode: ____________________
Immediate target: ____________________
Device / OS / input setup: ____________________
Reduced motion / sound / sensory settings: ____________________
Caregiver present: yes / no    Child assent confirmed: yes / no / withdrawn
Evidence status: Pending review
```

Do not enter a child's name, initials, age, school, location, contact details, diagnosis, health information, photo, audio, video, or free-text detail that could identify them.
