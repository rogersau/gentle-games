# Device And Input Matrix

This is a small proposed validation matrix, not evidence that these combinations have passed. Mark each cell only after a real, reviewed check. Use a representative supported device and record exact model and OS in the private study record.

| Setup | Core checks |
| --- | --- |
| Android phone or tablet, touch | Tap targets, no-drag alternatives, portrait/landscape layout, pause/stop/leave, sound and motion settings |
| iPhone or iPad, touch | Same touch checks, VoiceOver labels, Dynamic Type or larger text if used, reduced motion |
| Desktop web, mouse/trackpad plus keyboard | Tab order, visible focus, Enter/Space activation, Escape or explicit leave control, no drag-only task |
| Android with TalkBack and switch access | Spoken labels, focus order, one-switch activation, pause/stop/leave, no time pressure |
| iOS with VoiceOver and Switch Control | Spoken labels, focus order, scanning and activation, pause/stop/leave, no time pressure |
| Any supported setup with reduced motion and muted sound | No essential information conveyed only by motion or sound; still/visual alternatives remain usable |

## Per-Setup Evidence Gate

For each setup, review at least one sensory/regulation game, one creative game, and one guided-practice game. Include a new-example transfer where the game has a target. A "pass" requires the child to retain control, not merely that the facilitator can operate the screen.
