# Gentle Games picture library

The 121 transparent PNGs in this directory were generated for Gentle Games with the built-in OpenAI image generation tool. The first set established the visual style. It served as the reference for four additional sheets covering animals, town objects, nature and musical instruments. The individual pictures were isolated from those sheets, centred and scaled onto 160 × 160 transparent canvases.

The generation brief called for one familiar subject per cell, softly textured gouache and coloured pencil, quiet colours, a prominent outline, and a silhouette readable at 32 pixels. The subjects are identified by the filenames. The brief excluded lettering, badges, scenery and background shadows.

Games render these pictures through `GamePicture`. Pass a catalogue name such as `turtle` or `guitar`. A standalone picture can take a translated label. When the surrounding button describes the picture, the image is decorative. Previously stored game symbols resolve to the same packaged artwork.
