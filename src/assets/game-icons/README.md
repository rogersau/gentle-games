# Gentle Games artwork

These transparent PNGs were generated as one cohesive set with the built-in OpenAI image-generation tool, then cropped and optimised to 512×512 for mobile use.

Shared art direction:

- Rounded, hand-painted storybook illustrations with subtle paper texture
- Powder blue, blush pink, muted lavender, mint, apricot, and warm yellow
- Soft outlines, generous padding, no text, and no background scene
- Calm, readable silhouettes suitable for a 72px game-card icon well

Each prompt paired that direction with a single game subject:

- `memory-snap`: four interlocking pastel puzzle pieces
- `drawing`: painter's palette and soft brush
- `glitter-fall`: pastel sparkle snow globe
- `bubble-pop`: three softly opaque bubbles
- `category-match`: overlapping apple and star cards
- `keepy-uppy`: blush balloon with a blue string
- `breathing-garden`: symmetrical five-petal flower
- `pattern-train`: lavender engine with two pastel carriages
- `number-picnic`: woven basket with fruit and a picnic cloth

The generated sources used a flat chroma-key background. The checked-in files have that background removed and retain transparent corners.
